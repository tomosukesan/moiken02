VISION

現場の課題を
医療者が自ら解決する

現場の医療職が、課題の解決策を「待つ側」ではなく、「創る側」として自ら課題を解決し、 医療の質の向上と業務の効率化を実現する。

Mission

  • 課題を解決するための「現場知」と「技術」を持った医療者を育てる
  • ものづくり医療人同士の新しい横断的コミュニティを形成する

Value

VALUE 01

Hands-on first

まず触ってみる
議論や構想の前に、手を動かす。小さく試し、動くものから考えます。

VALUE 02

From field, for field

現場から現場へ
課題も解決策も現場発。現場で使えるかたちにして、現場へ返します。

VALUE 03

Open & Horizontal

ひらかれた横断コミュニティ
職種・施設・分野の垣根なく、対等につながります。

第2回のテーマ

「現場の課題から、未来の医療をつくる。」

第2回は、課題を見極める「判断する力」と、自ら形にする「実装する力」の2つを軸に、 公募発表・主催企画・対談セッション・交流を通じて、参加者が「明日から動き出せる」状態になることを目指します。

第1回は2025年11月23日に東京芸術センター（東京都足立区）で開催し、約30名が参加しました。（第1回 開催報告）

プログラム構成（予定）

公募発表ブロック

主催企画

医療とものづくりの現場に立つ方をお招きし、これからの医療のつくり方について語り合います。
